这套工程把采样拆成 **快环功率量（ADC1）** 和 **慢环辅助量（ADC2）** 两路，硬件定时器触发 + DMA 搬数，CPU 只在传输完成中断里做标定和滤波。

---

## 总览

```
TIM3 TRGO (~40 kHz) ──► ADC1 扫描 5 通道 ──► DMA1_CH1 (优先级很高)
                                              └─ TC 中断 → interrupt_ADC1()
                                                   ADC0_Sample() 标定
                                                   HandleFast()  控制/保护/PWM

TIM15 TRGO (~1 kHz) ──► ADC2 扫描 8 通道 ──► DMA1_CH2 (优先级低)
                                              └─ TC 中断 → interrupt_ADC2()
                                                   ADC2_Sample() 温度/风扇/辅源
```

启动在 `main.c`：`HAL_ADC_Start_DMA` 后再 `HAL_TIM_Base_Start`，定时器一跑，ADC 就周期触发。

---

## 1. ADC1：功率快采样（进控制环）

| 项目      | 配置                                                  |
| --------- | ----------------------------------------------------- |
| 外设      | **ADC1**，独立模式，12 bit                            |
| 驱动/搬运 | **DMA1 Channel1**，循环模式，优先级 `VERY_HIGH`       |
| 触发      | **TIM3 TRGO**，上升沿（`ADC_EXTERNALTRIG_T3_TRGO`）   |
| TIM3      | `PSC=16`，`ARR=249`，TRGO=`UPDATE`                    |
| 节拍      | SYSCLK=170 MHz 时约 **40 kHz**（25 µs 一拍）          |
| 采样时间  | 24.5 ADC 时钟（比 ADC2 更长，功率通道更稳）           |
| NVIC      | DMA1_CH1 优先级 **1**（高于 ADC2）                    |
| 软件入口  | `interrupt_ADC1()` → `ADC0_Sample()` → `HandleFast()` |

通道顺序（Rank = `ADC0_Buffer[]` 下标）：

| Buffer | ADC 通道 | 引脚            | 信号             | 处理后                               |
| ------ | -------- | --------------- | ---------------- | ------------------------------------ |
| `[0]`  | IN8      | PC2 `Vout1_adc` | 继电器侧输出电压 | `vOut_Rly_adc`（环路直接用）         |
| `[1]`  | IN9      | PC3 `Vout2_adc` | 电池电压         | `vOut_Bat_adc` + 慢 `vOut_Bat_FIR`   |
| `[2]`  | IN1      | PA0 `Iout_adc`  | 输出电流         | `iOut_Bat_adc` + 慢 `iOut_Bat_FIR`   |
| `[3]`  | IN3      | PA2 `S12V_adc`  | 12 V 辅源        | 在 **ADC2 中断**里才滤成 `AuxVolt`   |
| `[4]`  | IN12     | PB1 `TEMP_S3`   | 变压器 NTC       | 在 **ADC2 中断**里查表成 `Temp3_adc` |

`ADC0_Sample()` 里对电流/电池电压做 `0.999/0.001` 慢滤波，给 CAN、切模式用；**PI 仍吃原始 `*_adc`**。

这一拍还会跑 `HandleFast()`：软件过流/过压、状态机、写 HRTIM。所以 ADC1 既是采样，也是 **控制节拍时钟**。

## 2. ADC2：辅助慢采样（温度、风扇、基准）

| 项目      | 配置                                                      |
| --------- | --------------------------------------------------------- |
| 外设      | **ADC2**，12 bit                                          |
| 驱动/搬运 | **DMA1 Channel2**，循环模式，优先级 `LOW`                 |
| 触发      | **TIM15 TRGO**，上升沿                                    |
| TIM15     | `PSC=169`，`ARR=999`，TRGO=`UPDATE`                       |
| 节拍      | 约 **1 kHz**（1 ms）                                      |
| 采样时间  | 12.5 ADC 时钟（通道多、变化慢，可短一些）                 |
| NVIC      | DMA1_CH2 优先级 **2**                                     |
| 软件入口  | `interrupt_ADC2()` → 只调 `ADC2_Sample()`，**不进功率环** |

| Buffer    | 通道/引脚          | 信号       | 处理                               |
| --------- | ------------------ | ---------- | ---------------------------------- |
| `[0]`     | IN17 PA4 `TEMP_S0` | 输出散热器 | NTC 查表 → `Temp0` + `NTC0_AD_FIR` |
| `[1]`     | IN13 PA5 `TEMP_S1` | 内部空气   | 另一张 NTC 表 → `Temp1`            |
| `[2]`     | IN3 PA6 `TEMP_S2`  | 输出端子   | 查表 → `Temp2`                     |
| `[3]~[6]` | 风扇电流           | FAN1~4     | `0.99/0.01` 滤波                   |
| `[7]`     | IN4 PA7 `REF_0V3`  | 1.5 V 基准 | `vRef_1v5` + 一阶滤波              |

变压器温度挂在 ADC1，却在 `ADC2_Sample()` 里用 `ADC0_Buffer[4]` 处理——温度不需要 40 kHz，跟着 1 ms 任务做查表即可。

---

## 3. 触发方式（共同点）

两路都是：

1. **不连续转换**（`ContinuousConvMode = DISABLE`）  
2. **外部定时器 TRGO 上升沿** 启动一轮扫描  
3. 扫完 Rank 全部通道后，DMA 循环写满缓冲区，产生 **传输完成 TC**  
4. 中断里不清空 DMA、不重新 `Start_DMA`（循环 DMA + `DMAContinuousRequests`），下一拍定时器再触发

不是“CPU 轮询 ADC”，也不是 HRTIM 同步采样。功率环节拍由 **TIM3 固定 40 kHz** 决定，和 LLC 开关频率（PWM/PFM 在变）解耦。

另外还有 **模拟保护**（不是 ADC）：DAC 给出过流/过压门槛，比较器硬件关波，比数字采样更快。

---

## 4. 这样分的好处

**按时间尺度拆开**

- 电压/电流：环路、保护要 10 kHz 以上，放 40 kHz ADC1。  
- 温度、风扇、辅源：秒级变化，1 kHz 足够，少占 CPU。

**控制节拍稳定**

- 若用开关周期触发 ADC，PFM 频率一变，采样周期也变，PI 离散化会漂。  
- TIM3 固定 40 kHz，PWM/PFM 怎么切，控制 Ts 不变。

**CPU 和 DMA 优先级匹配**

- ADC1 DMA 最高：25 µs 内必须采完并跑完 `HandleFast`。  
- ADC2 低优先级：温度查表、风扇滤波可被快环打断，不影响占空比/频率更新。

**两颗 ADC 并行**

- ADC1/ADC2 独立触发、独立 DMA，快慢互不等待。  
- 扫描通道多时，慢量不会拉长快环转换时间。

**DMA 循环搬数**

- CPU 不读 ADC 数据寄存器，减少抖动。  
- 中断只做标定、滤波、控制，职责清楚。

**采样时间按用途设**

- 功率通道 24.5 周期，阻抗/噪声更好。  
- NTC/风扇 12.5 周期，1 ms 一拍足够。

## 5. 软件处理分层（对应“怎么分采样”）

| 层                     | 做什么                                       | 频率           |
| ---------------------- | -------------------------------------------- | -------------- |
| 硬件 ADC+DMA           | 原始 12 bit 进 `ADC0_Buffer` / `ADC2_Buffer` | 40 kHz / 1 kHz |
| `ADC0_Sample`          | 乘增益 → 工程量；电流/电池慢 FIR             | 40 kHz         |
| `HandleFast`           | 保护 + 状态机 + 环路（用原始 adc）           | 40 kHz         |
| `ADC2_Sample`          | NTC 查表、风扇/辅源/基准滤波                 | 1 kHz          |
| 慢任务（1 ms SysTick） | OTP、继电器、CAN 上报用 `*_FIR`              | ~200 Hz 分时   |

---

## 6. 使用上要注意的两点

1. **辅源、变压器温度** 的原始值在 ADC1，滤波/查表在 ADC2 中断。ADC2 未跑起来时，这两路更新会停，功率环不受影响。  
2. **快慢滤波不要混用**：`iOut_Bat_FIR` 约 25 ms，只适合显示和切模式；环路继续用 `iOut_Bat_adc`。

若要画板级对应关系：功率反馈走 ADC1 + TIM3；热管理和风扇走 ADC2 + TIM15；过流过压硬件走 DAC+比较器，三路并行。
