## 1. 快速状态机只生成状态变量或调用函数

### 原问题

`PowerCtrHandle()` 的 `NoSelect` / `ConCurPWM` / `Transition` / `OvLoadPFM` case 内直接写 PI、占空比、频率。

### 怎么改

**文件：** `AppUser/mathR02.c`、`AppUser/mathR02.h`

- 增加 `reqMode`：Handle 只 `RequestMode(下一态)`，由 `PowerCtrHandle` 末尾写 `CtrMode`。非法枚举丢弃（`PwmHold` 为枚举最后一项）。
- 每个 case 只调函数：

| `CtrMode` | 调用 |
|-----------|------|
| `NoSelect` | `ConIdleHandle()` |
| `SoftStar` | `SoftStart()` |
| `BmsStar` | `SoftCurStart()` |
| `SoftCurSt` | `ConVoltCurHandle()` |
| `ConVolt` | `ConVoltHandle()` |
| `ConCurPWM` | `ConCurrHandle()` |
| `PwmHold` | `ConPwmHoldHandle()` |
| `Transition` | `ConTransHandle()` |
| `OvLoadPFM` | `ConPfmHandle()` |

慢状态机（`ChargeOn` / `ConVoWakeup` 等）仍可直接写 `CtrMode`，属于高层模式指挥，不在快环里写控制公式。

### 是否达到

**达到。** 快环状态机内不再出现 `err`、PI、`Duty` 计算。

## 2. 不同模式切换（PWM→PFM）必须通过状态机

### 原问题

`ConCurPWM` 内部用 `psmSwitch` 0/1/2 隐式切到 `Transition` / `OvLoadPFM`。

### 怎么改

- 删除 `psmSwitch`，增加状态 **`PwmHold`** 和相位 `holdPhase`。
- 路径与原来阈值一致：

```
ConCurPWM  -- Vbat≥40V -->  PwmHold(phase1, Duty=0.04, I_FIR<1A 满 40 拍)
                         --> PwmHold(phase2, Duty=0.05)
                         --> Transition (Duty 斜坡 400 拍)
                         --> OvLoadPFM
```

- `SoftCurStart` 仍按电池电压请求 `ConCurPWM` 或 `Transition`（原高压直进过渡路径保留），改为 `RequestMode()`。

### 是否达到

**达到。** PWM/PFM 切换只改 `CtrMode`，不再靠同一函数里改 `Duty`/`Plv` 偷偷换模式。  
波形层 `SHRTIMERdrive()` 仍按 `CtrMode == OvLoadPFM` 选 PFM/PWM 比较器，只读模式、不改模式。

## 3. 电压电流采样统一低通后再进控制环

### 原问题

- `ADC0_Sample()` 只有电池电压/电流的慢 FIR（α=0.001，约 25 ms）。
- 环路用原始 `*_adc`；继电器电压无滤波。
- PFM 对 **误差** 再做 `OneOrderForm`，与采样滤波不是同一入口。

### 怎么改

**文件：** `AppUser/HwConfig.h`、`mathR02.c`、`ConsoleFast.c`

1. 增加环路滤波量：`vOut_Rly_LPF`、`vOut_Bat_LPF`、`iOut_Bat_LPF`。
2. 新增 **`SampleLpfHandle()`**，用 `FilterOne`（约 4 kHz）对三路做 `OneOrderForm`。
3. `HandleFast()` 在保护之前、`PowerCtrHandle()` 之前调用。
4. 环路反馈改读 `*_LPF`：`ConVoltHandle`、`ConCurrHandle`、`ConVoltHandleTwo`、`ConPfmHandle`、预充里用到的继电器电压。
5. PFM 去掉误差上的 `OneOrderForm`，避免与采样 LPF 双重滤波。

**未改（有意）：**

- `*_FIR`（0.999）仍给 CAN、切模式 `I<1A`。
- 软件过压/过流、同步管电流门槛仍用 `*_adc`（要快）。

### 是否达到

**达到。** 进环的电压电流都经过同一函数、同一套 `FilterOne`。  
动态会与改前略有差别，**环路参数需后期整定**（见第 5 节宏）。

## 4. 参考指令的限制和缓变（PWM / PFM 分家）

### 原问题

电流/电压指令限幅、斜坡散落在：

- `ConPfmHandle`：功率限、OTP 降额、`Curr_REF ±0.0002`
- `ConCurrHandle`：上限 10 A、相对实测 ±1 A 再斜坡
- `ConVoltHandle`：`Volt_Ref=30` 及 `vRly+0.01` 软爬升
- `ConTransHandle`：再读一遍 CAN 电流

原规范字面是收到 **一个** `RefLimitRamp()`。若硬合成，会把 PWM 的 ±1 A 窗和 PFM 的功率/OTP 拧到一起，爬坡动态会变。

### 怎么改（后续约定：行为可分开）

**文件：** `mathR02.h`、`mathR02.c`

| 函数 | 职责 | 不改的门槛 |
|------|------|------------|
| `RampToward()` | 仅 ±`REF_RAMP_STEP`(0.0002) 逼近，无跟踪窗、无限幅 | — |
| `RefRampPwmCurr()` | 钳 `PWM_CURR_MAX_CLAMP`(10 A)；仅在实测电流 ±`PWM_CURR_TRACK_BAND`(1 A) 窗内爬坡 | `CurrentMax > 0.1 A` 仍在 `ConCurrHandle` |
| `RefRampPfmCurr()` | 功率 P/V、`CON_CURR_OUT`、OTP×0.5/0.75 后再直追 `CurrentMax` | `CurrentMax > 0.5 A` 仍在 `ConPfmHandle` |

- CAN 电流仍由 `UpdateCurrentMaxFromCan()` 写入 `CurrentMax`，再进各自缓变。
- 电压环 `vRly+0.01` 软追上 **仍在** `ConVoltHandle`，不塞进电流缓变。
- `ConVoltHandleTwo` 的 `limRef` 仍是占空比限幅，不是 `Curr_REF`。

未做：单一 `RefLimitRamp()`、电压指令与电流指令合成一套 slew。

### 是否达到

**按分家约定达到。** 原规范「一个函数」字面不满足，工程上按 PWM/PFM 两套策略落地，公式与改前一致。

## 5. 环路控制函数结构一致；PI 增量核统一、位置式分家

### 原问题

- `ConVoltHandle` / `ConCurrHandle` / `ConVoltHandleTwo` 手写增量 PI；PFM 用 `Compensator_Pid`。
- `piExter_Compute` 与增量公式重复，工程无调用。
- 原规范后半句要求全部走同一套 `Compensator_Pid`。被控量（Duty vs Plv）和误差符号相反，合并会强制重整定。

### 怎么改（约定：骨架一致；增量式统一；位置式留给 PFM）

**前半：结构一致 — 已做**

各闭环 Handle 骨架：

```
读 *_LPF 与参考
→ 电流环：RefRampPwmCurr / RefRampPfmCurr
→ 算误差（及该模式原有限幅）
→ 调用本模式补偿器
→ 输出限幅
→ DriveSet(DrvH, DrvL, SynDrv, Plv, Duty)
```

| 函数 | 补偿器 |
|------|--------|
| `ConVoltHandle` | `PiPwmCompute`（电压 + 电流限制双环取小） |
| `ConCurrHandle` | `PiPwmCompute`（电流） |
| `ConVoltHandleTwo` | `PiPwmCompute`（电压） |
| `ConPfmHandle` | `Compensator_Pid`（频率 / 周期） |

PWM 增益收到宏（后期调参只改这里）：

| 宏 | 用途 | 现值 |
|----|------|------|
| `PWM_V_KP` / `PWM_V_KI` | 恒压电压环 | 0.04 / 0.001 |
| `PWM_I_LIM_KP` / `PWM_I_LIM_KI` | 恒压电流限制 | 0.02 / 0.004 |
| `PWM_CUR_KP` / `PWM_CUR_KI` | 恒流 PWM | 0.0005 / 0.001 |
| `PWM_CV2_KP` / `PWM_CV2_KI` | `ConVoltHandleTwo` | 0.04 / 0.001 |

**增量核统一 — 已做**

- 唯一增量公式在 `PiPwmCompute()`：`Δu = Kp*(e−e_prev)+Ki*e`，`integral` 存上一拍误差；调用方再累加 `oldout` 并限幅。
- `piExter_Compute()` 改为转调 `PiPwmCompute(p, input, p->Kp, p->Ki)`。
- 各环 Kp/Ki **不共用** 一组增益。

**位置式 — 不并入 PWM（有意）**

- PFM 仍 `Compensator_Pid`：`integral += Ki*e`；`y = integral + Kp*e`；再 ×50000 得 `Plv`；超限钳 `PID_MAX_PLV` / `PID_MIN_PLV`。
- 误差符号：PWM 为 `Curr_REF − I`，PFM 为 `I − Curr_REF`。电流偏大时 PWM 降占空比、PFM 加长周期降频。
- PFM 的 Kp/Ki 仍在 `piStructInter`，滤波系数仍在 `FilterOne`。

开环预充 `SoftStart` / `SoftCurStart` 仍是查表占空比，不是 PI。

### 是否达到

- 结构一致：**达到**
- PWM 增量核统一：**达到**
- PWM/PFM PI 合成一套：**未做（有意）**，规范第 5 条原后半句不满足，与约定一致

## 7. 驱动使能、PWM 频率、占空比只在环路函数里配置

### 原问题

- 快状态机 case 内写 `DriverPwm`
- `HandleFast` 故障路径 `PwmClose()` + `Plv`
- `StateMErr` 里 `PwmClose()`
- `SHRTIMERdrive` 按电流改 `SynDrv`

### 怎么改

| 位置 | 改法 |
|------|------|
| `PowerCtrHandle` | 不再写 `DriverPwm` |
| `HandleFast` 故障 / PFC 未就绪 | 置 `CtrMode=NoSelect` 后 **同一拍** 调 `PowerCtrHandle()` → `ConIdleHandle()` 关波 |
| `StateMErr` | 去掉 `PwmClose`，只置 `NoSelect`（下一拍 ADC 进 Idle 关波，约 ≤25 µs） |
| 同步管按电流开通 | 从 `SHRTIMERdrive` 上收到 `PwmSyncDrvUpdate()`，由 `ConCurrHandle` / `ConPwmHoldHandle` 调用 |
| PFM 电流 &lt;4 A 清同步管 | 在 `ConPfmHandle` |
| 驱动赋值 | 闭环 Handle 用 `DriveSet()`（duty 钳 [0,1]，正常工况碰不到） |

**允许写驱动的函数：**  
`ConIdleHandle`、`SoftStart`、`SoftCurStart`、`ConVoltCurHandle`、`ConVoltHandle`、`ConCurrHandle`、`ConVoltHandleTwo`、`ConPwmHoldHandle`、`ConTransHandle`、`ConPfmHandle`。

**残留（不完全禁止写 `DriverPwm`）：**

1. `starLowIni()` 仍 `PwmClose()` —— 上电、快环尚未跑，建议保留。
2. `HandleFast` 仍 `LLC_Enable` / `LLC_Disable` —— LLC 使能未完全收到 Handle；故障关波已在 Idle。
3. `SHRTIMERdrive` 在脉宽过短或非 PWM 电流态仍会清 `SynDrv` —— 比较器时基约束，属落地保护，不是策略环。

**勿套用：** `PWM_MAX_DUTY=0.15` 为历史宏，环路占空比上限仍为 0.4。

### 是否达到

**基本达到。** 状态机不再配置频率/占空比/管脚使能；关波在 Idle Handle。LLC 使能与 HRTIM 脉宽保护仍有少量驱动层写入。

## 快环当前调用顺序

```
ADC1 DMA TC (≈40 kHz)
  → ADC0_Sample()           // 原始标定 + 慢 FIR（CAN/切模式）
  → HandleFast()
       SampleLpfHandle()    // 规则3：进环 LPF
       保护（仍用 *_adc）
       PowerCtrHandle()     // 规则1：只调 Handle；规则2：切 CtrMode
         ├─ RefRampPwmCurr / RefRampPfmCurr   // 规则4：缓变分家
         ├─ PiPwmCompute / Compensator_Pid    // 规则5
         └─ DriveSet()                        // 规则7
       SHRTIMERdrive()      // 只落地比较器/GPIO
```

## 后期调参建议

进环增加约 4 kHz 一阶滤波后，PWM/PFM 带宽会略变，建议台架按下面顺序动宏，**不要先改 PI 结构、不要把两套缓变合成一套**：

1. 恒压起机、30 V 调节：`PWM_V_KP` / `PWM_V_KI`
2. PWM 恒流跟随：`PWM_CUR_KP` / `PWM_CUR_KI`
3. CV 模式（`ConVoltHandleTwo`）：`PWM_CV2_KP` / `PWM_CV2_KI`
4. PFM：`piStructInter.Kp/Ki` 与 `FilterOne`
5. 若噪声仍大或过钝：再动 `FilterOne` 系数（会同时影响三路 `*_LPF`）
6. 缓变快慢：只动 `REF_RAMP_STEP`；PWM 跟踪窗动 `PWM_CURR_TRACK_BAND`，不要改 PFM 那支
