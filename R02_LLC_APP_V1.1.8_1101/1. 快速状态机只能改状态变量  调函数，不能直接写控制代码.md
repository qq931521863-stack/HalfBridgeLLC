# 快速状态机与控制架构对照（规范 1～5、7）

> 工程：`R02_LLC_APP_V1.1.1_0824`  
> 本文原为改前定位稿。代码已按约定落地后，改为 **原问题 → 现状 → 是否达到**。  
> 原需求未列第 6 条。细则与文件清单见 `控制架构整改清单.md`。

当前快环调用链：

```
ADC1 DMA TC (≈40 kHz)
  → ADC0_Sample()            // 原始标定 + 慢 FIR（CAN / 切模式）
  → HandleFast()
       SampleLpfHandle()     // 规则3：进环 LPF
       保护（仍用 *_adc）
       PowerCtrHandle()      // 规则1：只 switch + 调 Handle；规则2：采纳 reqMode
       SHRTIMERdrive()       // 读 DriverPwm，写 HRTIM；脉宽过短仍可能清 SynDrv
```

---

## 1. 快速状态机只能改状态变量 / 调函数，不能直接写控制代码

**判定：达到。**

### 原问题

`PowerCtrHandle()` 的 `NoSelect` / `ConCurPWM` / `Transition` / `OvLoadPFM` case 内直接写 PI、占空比、频率。`psmSwitch` 嵌在 `ConCurPWM` 里。

### 现状

`PowerCtrHandle()` 只做：同步 `reqMode` → `switch` 调 Handle → 采纳 `reqMode` 写 `CtrMode`。

| `CtrMode` | 调用 |
|-----------|------|
| `NoSelect` | `ConIdleHandle()` |
| `SoftStar` | `SoftStart()` |
| `BmsStar` | `SoftCurStart()` |
| `SoftCurSt` | `ConVoltCurHandle()` |
| `ConVolt` | `ConVoltHandle()` |
| `ConCurPWM` | `ConCurrHandle()` |
| `PwmHold` | `ConPwmHoldHandle()` |
| `Transition` | `ConTransHandle()` |
| `OvLoadPFM` | `ConPfmHandle()` |

Handle 切模式只调 `RequestMode()`，非法枚举丢弃。快环状态机内不再出现 `err`、PI、`Duty` 计算。

慢状态机（`ChargeOn` / `ConVoWakeup` / 故障置 `NoSelect`）仍可直接写 `CtrMode`，属于高层指挥。

## 2. PWM↔PFM 切换必须走状态机

**判定：达到。**

### 原问题

`ConCurPWM` 内部 `psmSwitch` 0/1/2 隐式切到 `Transition` / `OvLoadPFM`。`SoftCurStart` 直接写 `CtrMode`。

### 现状

删除 `psmSwitch`，增加显式状态 **`PwmHold`** 和相位 `holdPhase`。路径与原阈值一致：

```
ConCurPWM  -- Vbat≥40V -->  PwmHold(phase1, Duty=0.04, I_FIR<1A 满 40 拍)
                         --> PwmHold(phase2, Duty=0.05)
                         --> Transition (Duty 斜坡 400 拍)
                         --> OvLoadPFM
```

- `ConCurrHandle` / `ConPwmHoldHandle` / `ConTransHandle` / `SoftCurStart` 只 `RequestMode()`。
- `SHRTIMERdrive()` 仍按 `CtrMode == OvLoadPFM` 选 PFM/PWM 比较器，只读模式、不改模式。

`SoftCurStart` 预充结束后仍按电池电压请求 `ConCurPWM` 或 `Transition`（原高压直进过渡路径保留），真正改 `CtrMode` 仍在 `PowerCtrHandle` 末尾。

## 3. 电压电流采样统一低通后再进控制环

**判定：达到。** 动态与改前略有差别，环路参数需后期整定。

### 原问题

环路用 `*_adc`；继电器电压无滤波；PFM 对误差再做 `OneOrderForm`。

### 现状

1. `HwConfig.h` 增加 `vOut_Rly_LPF`、`vOut_Bat_LPF`、`iOut_Bat_LPF`。
2. `SampleLpfHandle()` 用 `FilterOne`（约 4 kHz）对三路做 `OneOrderForm`。
3. `HandleFast()` 在保护之前调用（先滤波，保护仍读 `*_adc`）。
4. 环路反馈读 `*_LPF`；PFM 去掉误差上的 `OneOrderForm`。

**未改（有意）：**

- `*_FIR`（0.999）仍给 CAN、切模式 `I<1A`。
- 软件过压/过流、同步管电流门槛仍用 `*_adc`。

## 4. 参考指令限幅和缓变

**判定：按后续约定达到（PWM/PFM 分家），不是合成一个 `RefLimitRamp()`。**

### 原问题 / 原规范字面

限幅、斜坡散落在 PWM 恒流、PFM、电压环多处；原规范要求收到 **一个** 函数。

### 后续约定

PWM 与 PFM 缓变 **行为可分开**，不要合成一套参数（PWM 有 ±1 A 跟踪窗，PFM 有功率/OTP 限幅）。电压环 `vRly+0.01` 软追上不是电流缓变。

### 现状

| 函数 | 做什么 | 谁调用 |
|------|--------|--------|
| `RampToward(ref, target, step)` | 仅 ±`REF_RAMP_STEP`(0.0002) 逼近 | 下面两函数 |
| `RefRampPwmCurr()` | 钳 10 A + ±1 A 窗 + `RampToward` | `ConCurrHandle`（门槛仍 `CurrentMax>0.1A`） |
| `RefRampPfmCurr()` | 功率 P/V、`CON_CURR_OUT`、OTP 后再直追 | `ConPfmHandle`（门槛仍 `CurrentMax>0.5A`） |

电压参考软追上仍在 `ConVoltHandle`，未塞进电流缓变。`ConVoltHandleTwo` 的 `limRef` 仍是占空比限幅，不是电流指令。

## 5. 环路函数结构一致；PI 控制器

**判定：结构一致达到；增量核统一达到；PWM 增量式与 PFM 位置式不合并（有意）。**

### 原问题 / 原规范字面

要求全部走 `Compensator_Pid`。PWM 手写增量 + `oldout`，PFM 用位置式，再加一套几乎无调用的 `piExter_Compute`。

### 后续约定

- 骨架可以一致。
- PWM / PFM 的 PI **可不同**。
- 增量式在 PWM 内统一；位置式留给 PFM，不统一进 PWM。

### 现状骨架

```
读 *_LPF 与参考
→ 电流环先 RefRampPwmCurr / RefRampPfmCurr（电压环仍自管参考）
→ 算误差（及该模式原有限幅）
→ 本模式补偿器
→ 输出限幅
→ DriveSet(...)
```

| 函数 | 补偿器 |
|------|--------|
| `ConVoltHandle` | `PiPwmCompute`（电压 + 电流限制双环取小） |
| `ConCurrHandle` | `PiPwmCompute`（电流） |
| `ConVoltHandleTwo` | `PiPwmCompute`（电压） |
| `ConPfmHandle` | `Compensator_Pid`（周期 / 频率） |

- `PiPwmCompute`：PWM 增量核，`Δu = Kp*(e−e_prev)+Ki*e`，各环 Kp/Ki 用宏。
- `piExter_Compute`：薄封装，转调 `PiPwmCompute(p, input, p->Kp, p->Ki)`；工程无调用点。
- `Compensator_Pid`：PFM 位置式，不与增量核合并。误差符号仍为 `I − Curr_REF`（与 PWM 的 `Curr_REF − I` 相反）。

开环预充 `SoftStart` / `SoftCurStart` 仍是查表占空比，不是 PI 环。

## 7. 驱动使能、PWM 频率、占空比只能在环路函数里配

**判定：基本达到。**

### 原问题

状态机 case、`HandleFast`、`StateMErr`、`SHRTIMERdrive` 都在写 `DriverPwm`。

### 现状

| 位置 | 改法 |
|------|------|
| `PowerCtrHandle` | 不再写 `DriverPwm` |
| `HandleFast` 故障 / PFC 未就绪 | 置 `NoSelect` 后 **同一拍** 调 `PowerCtrHandle()` → Idle 关波 |
| `StateMErr` | 去掉 `PwmClose`，只置 `NoSelect` |
| 同步管按电流开通 | `PwmSyncDrvUpdate()`，由 `ConCurrHandle` / `ConPwmHoldHandle` 调用 |
| PFM 电流 &lt;4 A 清同步管 | 在 `ConPfmHandle` |
| 闭环写驱动 | `DriveSet()` |

**允许写驱动的函数：**  
`ConIdleHandle`、`SoftStart`、`SoftCurStart`、`ConVoltCurHandle`、`ConVoltHandle`、`ConCurrHandle`、`ConVoltHandleTwo`、`ConPwmHoldHandle`、`ConTransHandle`、`ConPfmHandle`。

**残留：**

1. `starLowIni()` 仍 `PwmClose()` —— 上电、快环尚未跑。
2. `HandleFast` 仍 `LLC_Enable` / `LLC_Disable`。
3. `SHRTIMERdrive` 在脉宽过短或非 PWM 电流态仍会清 `SynDrv`（比较器时基约束）。
